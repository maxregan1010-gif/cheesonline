نسخه کامل شطرنج آنلاین

امکانات قوانین اضافه‌شده:
- قلعه کوتاه و قلعه بلند با کنترل کیش و خانه‌های عبوری
- آن‌پاسان
- ترفیع سرباز به وزیر، رخ، فیل یا اسب
- کیش، کیش‌ومات و پات
- تساوی به علت تکرار سه‌باره موقعیت
- تساوی طبق قانون ۵۰ حرکت
- تساوی به علت کمبود مهره برای مات
- پیشنهاد مساوی و قبول/رد
- تسلیم
- تایمر ۵ دقیقه‌ای برای هر بازیکن
- اعتبارسنجی حرکت‌ها و قوانین اصلی سمت سرور
- حفظ نوبت، حق قلعه، آن‌پاسان و شمارنده نیم‌حرکت روی سرور

Render:
Build Command: npm install
Start Command: npm start
